# XSupport

XMARKET support console — standalone React + Vite PWA sharing the XMARKET Supabase DB.

## Features
- Supabase auth (same accounts as XMARKET)
- Reports dashboard with edit + delete
- Tools placeholder (search, filter, export, broadcast)
- Installable PWA

## Dev
    npm install
    npm run dev

## Build
    npm run build

## Deploy
Pushed to Render as static site (see render.yaml).
